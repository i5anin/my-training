# Снимки техники упражнений

Файл кладётся под именем id упражнения из каталога, формат webp:

    pallof-press.webp

После добавления файла упражнение нужно перечислить в
`src/constants/exercisePhotos.ts` — список явный, чтобы каталог
не сыпал 404 на упражнения без снимков.

Кадр горизонтальный — ставьте `landscape: true`.
